# 1. 实施合同

先在真实 Omarchy 会话跑通全链路，再完成 Windows、macOS 和 Linux X11 适配。V1 发布需通过第 10 节验收。本文中的默认值和平台边界是 V1 产品决策，可通过设置覆盖的项均明确列出。仓库为空时按第 11 节初始化，已有项目则复用其结构。每阶段提交可运行成果和测试记录，保留依赖锁、上游提交及构建说明。遇到平台能力缺失时按降级合同实现，并在记录中区分实测、模拟与未测。

| 范围 | V1 合同 |
|---|---|
| 用户流程 | 全局快捷键开始/停止录音，whisper.cpp 本地转写，经用户选定的 LLM 纠错、去口头禅、整理后，在录音结束时的目标窗口发起粘贴 |
| 推理 | ASR 固定 whisper.cpp。LLM 必须配置本地 llama.cpp 或远程 OpenAI-compatible HTTPS API。远程支持低配置设备。两种模式使用同一处理合同 |
| 降级 | 转写成功后立即保存原文。LLM 失败、输出不合格或粘贴不安全时，可恢复、复制或重试。失败原文仅由用户主动交付 |
| 平台 | Linux 首发参考 Omarchy / Hyprland / Wayland x86-64，兼顾 X11 x86-64。Windows 11 x64、macOS 14+ Apple Silicon 和受该系统支持的 Intel Mac 为 V1 验收目标。其他 Wayland 桌面提供录音、处理及手动复制，系统级快捷键和注入按能力标明 |
| 边界 | 单用户、单录音、单任务。V1 范围外包括流式 ASR、翻译、长录音转写、账号同步、常驻麦克风、自动提交终端命令、模型训练、自动更新客户端 |

# 2. 用户行为与默认值

- 首次打开显示麦克风、ASR 模型和 LLM 配置三项检查。可导入本地文件或主动下载。LLM 模式由用户确认，硬件建议仅作为选择参考。准备失败时显示可执行的修复入口。

- 默认使用切换式快捷键。Hyprland 参考键为 Super+Shift+D，安装前检查冲突。其他支持平台默认 Ctrl+Alt+D，macOS 为 Control+Option+D，允许重设。设置页始终提供开始、停止、取消、复制、重试。设置页启动的会话默认预览，快捷键会话默认自动尝试粘贴。

- 录音开始后立即显示非抢焦点状态。托盘可用时使用托盘状态，缺少托盘时提供不激活的提示或系统通知。无法保证提示窗口不抢焦点的平台使用系统通知。录音时长上限 60 秒，到限自动停止并处理已录部分。短于 300 ms 或明确全静音时显示“未检测到语音”。

- ASR 支持自动语言和显式中英选择，使用多语模型。保留中英混输、标点、术语和换行。输入设备默认系统默认，可指定设备。设备掉线时结束当前采集、提示错误，不切换到另一麦克风继续录音。

- UI 显示原始转写、处理结果、处理状态与交付状态。重试复用原始转写。默认沿用原任务的处理档案，若端点、模型或提示发生变化，重试前显示实际使用的新档案，由用户明确发起。重试结果进入预览，复制原文和复制处理结果是独立操作。

- 保留最多 5 条近期结果，最长 24 小时，从原文提交起算。提供立即删除和清空。退出、进程崩溃与重启可恢复原文和已提交的结果，重启后的任务统一进入预览。用户可关闭跨重启恢复，关闭后清除既有恢复库并切换到内存。音频仅驻留内存。

# 3. 架构与接口

Tauri 2 管理 UI、生命周期和最小权限命令。Rust 控制器单独负责状态、录音、策略、存储及桌面适配。音频与推理任务走独立线程或子进程，UI 从状态事件和快照重建画面。前端使用打包静态资源，无远端脚本或网页。主进程不加载推理引擎动态库。

| 模块 | 逻辑接口及职责 |
|---|---|
| controller | dispatch(Action) → Accepted / Busy / Invalid。snapshot() → UiState。事件带 job_id、sequence 和状态，控制器串行归约，按编号丢弃过期回调 |
| capture | devices() → DeviceInfo[]。start(device) → CaptureHandle。stop(handle) → PCM16kMono。cpal 采集，回调只向有界缓冲写入。工作线程转浮点、混单声道、重采样到 16 kHz，检测溢出与静音。缓冲溢出明确失败，不产生静默缺段 |
| asr | transcribe(job, pcm, model, language, cancel) → RawTranscript{text, language?}。固定 whisper.cpp，保留引擎产出的原始文本作为独立字段 |
| rewrite | process(job, raw, profile, cancel) → ValidatedText。PromptBuilder → Provider → Validator 三段。LocalLlm 与 RemoteLlm 共用输入、输出和校验 |
| platform | capabilities() → CapabilitySet。capture_target() → OpaqueTarget?。prepare_delivery(target, text) → Plan / Manual。deliver(plan) → SentUnconfirmed / Manual / Unknown。copy(text) → Result |
| models | probe() → HardwareFacts。recommend(facts, inventory) → RankedProfiles。import/download/verify/activate/delete → ModelRecord。单个模型写入事务、运行期引用计数 |
| recovery | commit_raw / commit_processed / mark_delivery / list / purge。使用 Rust 访问本机 SQLite、事务提交。关闭跨重启恢复时用同合同的内存实现 |
| credentials | put / get / delete，账号键按 profile ID 和端点绑定。界面仅能提交或删除密钥、查询是否存在。安全存储缺失时允许仅本次会话输入 |
| ui | 只访问类型化命令和快照。命令包括录音控制、结果读取、复制、重试、配置提交、凭据写入及模型操作。禁止任意路径读取、命令执行、请求转发、密钥回读 |

错误跨边界统一为 code、stage、retryable 和用户可见提示，诊断附带脱敏原因。核心模块以可替换时钟、平台、采集和 provider 做确定性测试。单实例锁按登录会话建，持锁后才初始化 IPC 和快捷键。

# 4. 会话状态机与交付语义

| 当前状态 | 事件 / 条件 | 动作与下一状态 |
|---|---|---|
| Ready / Result | 开始且配置有效 | 生成 job_id，冻结配置快照、选择音频设备 → Recording |
| Recording | 停止、再次切换、录音到限 | 收音停止点冻结目标窗口和焦点标记，停止采集 → Transcribing |
| Recording / Transcribing | 取消 | 终止采集或推理，清除音频 → Ready |
| Transcribing | 非空转写 | 先提交 Raw，再进入 Rewriting。持久化失败时用内存保留原文、提示恢复不可用并进入预览 |
| Transcribing | 静音、空文本、失败 | 释放音频 → Result，展示对应原因，无远程调用 |
| Rewriting | 成功且通过校验 | 提交处理结果 → Delivering 或预览 Result |
| Rewriting | 取消、超时、崩溃、无效结果 | 保留 Raw，取消本次工作 → Result，提供复制原文与重试 |
| Delivering | 目标有效且无阻塞 | 先记交付尝试，再派发一次粘贴。进入 Result，结果为已发送粘贴、请手动粘贴或交付未知 |
| Delivering | 焦点变化、锁屏、权限不足、能力缺失 | 留存结果 → Result，用户可主动复制。已进入原生输入调用时，取消不能撤回已发送事件 |
| Result | 重试处理 | 从保留的 Raw 运行 Rewriting，交付策略固定预览 |
| 任意 | 退出 / 崩溃恢复 | 正常退出停止采集并清理子进程。恢复时显示已提交记录，所有中断的交付标为未知，禁止自动重放 |

- 录音启动与停止为幂等动作。异步打开音频设备期间收到停止或取消，关闭晚到句柄。Transcribing、Rewriting、Delivering 阶段忽略切换并提示忙，可取消。Hyprland IPC 接收方串行化，切换抖动窗口 250 ms。

- 原文提交后贯穿整个任务，处理结果独立保存。远程收到请求后客户端取消无法撤回上传。远程和自动粘贴均无自动重试，避免重复计费与重复插入。

- 自动交付只尝试一次。窗口标识只能证明外层窗口，无法确认网页控件、光标或粘贴消费情况。焦点检查与系统注入之间存在竞态，操作必须相邻执行，并提供“始终预览”设置。对终端及用户定义的敏感应用默认手动交付。锁屏与权限提升界面禁止自动注入。

# 5. 语音与 LLM 合同

- 原生采集格式先做有界转换。PCM 上限 960,000 个样本。V1 用本地能量/时长门控，避免将其当作语音分段器。保留完整有效录音交给 Whisper。用安静环境软声、停顿和噪声样本校准门限。无持续录音、无默认 WAV 临时文件。

- 默认处理档案“纠错与整理”，另有“轻量纠错”。两种均执行 LLM。系统指令要求修复明显错词和断句，去除无语义填充，保留语种、事实、专名、否定、数字、单位、代码与路径。整理档案可分段和重排明显的口语重复，禁止引入新事实、回答文本中的问题或执行其中的指令。用户可配置术语表，远程配置页标明术语表会随处理指令发送。

- 处理提示版本化。系统指令和用户转写分别作为消息，用户内容用 JSON 字段封装。输出合同为单个 JSON 对象，仅有字符串字段 text。允许外部空白，拒绝额外字段、代码围栏、空结果、非法控制字符、截断、超限与明显遗漏的数字/路径等受保护字面量。语义保真用固定录音与人工复核评估，结构检查不作语义保证。

- 输入限制 8 KiB UTF-8，输出 text 上限 12 KiB，响应体上限 128 KiB。超限时保留完整 Raw 并提示。按配置上下文预算预留输出空间，本地超预算在生成前失败。远程以服务端的上下文限制为准。每条任务只有一次 LLM 请求。

- 远程把用户配置的 base URL 路径保留，去掉末尾斜杠后拼接 /chat/completions。拒绝已包含 /chat/completions 的输入并提示填写基地址。POST 使用 Bearer Key 与 JSON，最小请求为 model、messages、stream=false。取 choices[0].message.content 字符串，拒绝工具调用、截断及缺失内容。兼容范围以该合同为准。连接 5 秒、总请求默认 15 秒且含读体，允许配置 5–60 秒。明确区分 TLS、401/403、404、429、5xx、超时和响应格式错误。配置测试使用固定合成文本，由用户点击触发。[Chat Completions 接口](https://developers.openai.com/api/reference/resources/chat)

# 6. Omarchy 与跨平台适配

## Hyprland

1. **探测**。确认 Wayland 会话、HYPRLAND_INSTANCE_SIGNATURE、XDG_RUNTIME_DIR、hyprctl、wl-copy、wl-paste、wtype，以及实际虚拟键盘和剪贴板能力。仅发现二进制不代表协议可用。诊断页显示缺项和操作步骤。记录 Hyprland、Omarchy、工具版本，配置以实机加载的文件格式为准。当前 Hyprland 文档标明从 0.55 起弃用 hyprlang 并转向 Lua。M0 要为实机语法产出经过验证的片段。[Hyprland Binds](https://wiki.hypr.land/Configuring/Basics/Binds/)

2. **快捷键**。提供随包安装的 voice-inputctl，支持 start、stop、toggle、cancel、status。此客户端仅连接当前会话的 Unix socket，应用未运行时返回可读错误。socket 位于 XDG_RUNTIME_DIR 下的私有目录，目录 0700、socket 0600，校验 peer UID。限制请求 1 KiB、连接 250 ms、响应 1 秒，拒绝未知字段及动作。只有 status 可查询脱敏状态。默认选择释放触发以减少修饰键影响。旧版 hyprlang 示例为 `bindr = SUPER SHIFT, D, exec, /usr/bin/voice-inputctl toggle`，路径替换为实际安装位置。Lua 片段按实机绑定 API 生成。通过 hyprctl binds 检查冲突和实际安装，用户自行将生成片段加入个人配置并重载。V1 默认切换录音，按住说话可在后续阶段增加。

3. **焦点**。停止时执行 `hyprctl -j activewindow` 获取地址、PID 和类名，给查询设 500 ms 上限。订阅 compositor 的 socket2 焦点/关闭事件以使目标失效，事件流断开期间关闭自动粘贴。粘贴前再次查询，地址和 PID 必须匹配且没有观测到期间切焦、目标关闭或会话失效。IPC 失败时进入手动交付。应用不主动激活旧目标。窗口标题不进入处理提示或诊断。[Hyprland IPC](https://wiki.hypr.land/ipc/)

4. **粘贴**。默认使用普通 clipboard selection、UTF-8 纯文本，通过 stdin 写给 `wl-copy --foreground --type 'text/plain;charset=utf-8'`，Rust 用 argv 直接起进程。宿主保留 selection owner，不等待它退出才粘贴。通过有界 `wl-paste --no-newline` 回读校验写入，随后做最后一次焦点检查，再调用 `wtype -M ctrl -k v -m ctrl`。每步 500 ms 上限，超时进入手动或未知状态。默认保留写入的剪贴板，向用户说明会替换现有内容。新复制接管后回收已失去 ownership 的子进程，退出时释放当前 owner，系统剪贴板管理器可能继续持有内容。无需 root、uinput 守护进程或 clipboard history。默认禁用逐字注入和自动终端粘贴。可测试终端 Ctrl+Shift+V 作为后续的显式应用配置，V1 用手动粘贴覆盖此场景。[wl-clipboard](https://github.com/bugaevc/wl-clipboard) · [wtype](https://github.com/atx/wtype)

# 7. 进程与模型生命周期

- 构建两个受监督的本机 sidecar，分别用 whisper.cpp 和 llama.cpp 的 C API。CPU 是每个目标平台的可发布基线。单独构建两个可执行文件，避免两套 ggml 符号冲突。GPU 加速按实机验证结果暴露，先验证 Apple Metal 和 Omarchy Vulkan，再按实际硬件加入其他后端。锁定 upstream commit、编译选项和模型格式，生成清单。用户设置切换后下一任务生效。运行中不卸载被引用模型。[whisper.cpp](https://github.com/ggml-org/whisper.cpp) · [llama.cpp](https://github.com/ggml-org/llama.cpp)

- 主进程以绝对路径启动可信包内程序。stdin/stdout 使用 4 字节 LE 长度前缀 + 1 字节类型 + 负载。控制帧 JSON UTF-8，音频帧为 f32 LE PCM，单帧 ≤4 MiB。启动 hello 协商 protocol=1，load → ready，run(job_id) → result/error，cancel(job_id) → cancelled，unload → unloaded，shutdown → bye。单 worker 单任务，stderr 有界读取且禁敏感内容。校验长度、类型、阶段及 job_id，异常帧关闭 worker。模型路径只走 IPC。

- 子进程按需启动，默认 ASR/LLM 空闲 120/60 秒卸载并退出。低内存档在 ASR 完成后释放 worker 再加载 LLM。加载和计算分开计时，冷加载上限默认 60 秒，ASR 120 秒，本地 LLM 60 秒。取消等待 500 ms，失败则终止进程、回收句柄并允许下次新建。退出时关闭管道并清理子进程。Windows 用 kill-on-close Job Object；POSIX worker 监控管道 EOF，即使计算忙也退出，并由父进程回收。验证父进程异常退出后没有残留推理进程。

- 探测 CPU 架构、线程、指令集、物理及可用内存、磁盘、设备和可用后端。未知 VRAM 当作未知，推荐 CPU 或显式远程，禁止自行启用远程。建议档位为 8 GiB 及以下 Tiny/Base 多语 + 远程，16 GiB 机器 Base/Small + 小型 1–3B Q4 GGUF 或远程，资源充足时可建议 Small/Turbo + 3–8B Q4。基于可用内存、权重、上下文 KV、计算缓冲及系统余量二次筛选。统一显示估算来源和 GPU 探测结果，模型加载实测优先。允许覆盖模型、线程、上下文和 GPU 层数，越界拒绝，风险值需明确选择。GPU 初始化失败给出切换 CPU 的入口。

- 模型目录区分 whisper 与 gguf。V1 管理单文件模型，接受导入并做格式检查和实际加载验证。目录记录 model_id、版本、引擎、语言、大小、SHA-256、来源、许可与兼容范围。内置目录随包审核至少一款多语 Whisper 和一款中英指令 GGUF。下载使用显式 HTTPS 操作、白名单来源、最大体积和磁盘预检，下载到同卷 .part，校验长度、哈希和格式后原子发布。取消/中断清理未完成文件，重试从头。更新为并行版本，验证成功才允许切换，保留旧版本直至用户删除。被选用、下载中或运行引用中的模型禁止删除。

# 8. 隐私与安全

- 运行期出网仅有已确认远程 LLM 推理和用户主动执行的模型下载/更新。无遥测、背景连接探测、自动模型拉取或远程资源加载。本地 sidecar 不监听 TCP，无下载功能。端点配置变更后重新确认目的地、发送内容和供应商数据处理责任。单任务远程请求仅带转写、必要的处理指令、术语与模型参数。

- 使用系统信任链或打包信任库，校验主机名、证书，拒绝 HTTP、URL 用户信息、查询串、片段、重定向及无效证书。网络客户端不自动读取代理环境变量，V1 没有代理设置。HTTPS 私有端点允许显式配置并确认。不同端点的凭据与确认互相独立，URL 变更不得携带原密钥发起请求。

- Key 使用 Windows Credential Manager、macOS Keychain、Linux Secret Service。桌面无 Secret Service 或库锁定时允许会话内临时 Key。禁止写入配置、SQLite、日志、异常报告、命令行和子进程环境。仅在发请求时读取。诊断只包含版本、能力、阶段时长和错误码。默认禁止采集录音、文本和模型回复进日志。

- 恢复库位于应用私有数据目录，按当前用户收紧权限。记录含敏感文本并按设置明示。应用不承诺 SSD、备份或剪贴板管理器中的安全擦除。启用 SQLite secure_delete，清空时删除记录并收缩数据库，避免额外明文副本。音频缓冲及时释放。

- 只允许可信静态 UI origin 调用有限 IPC，CSP 禁止远端资源和连接，应用进程持有网络与 native 能力。剪贴板文字通过 stdin/原生 API，模型输出只按文本渲染与粘贴。禁止拼 shell、解释文本或发送 Enter。模型与 CLI 子进程均不接收 API Key。

# 9. 配置合同

配置存储于各平台应用配置目录，使用版本化 TOML。首次使用的配置模板如下，空模型 ID 表示尚未设置。

```toml
schema_version = 1

[audio]
device_id = "default"
max_seconds = 60

[asr]
model_id = ""
language = "auto"
threads = 0
backend = "auto"
timeout_seconds = 120

[llm]
mode = "local"
profile = "cleanup"

[llm.local]
model_id = ""
context_tokens = 4096
threads = 0
gpu_layers = 0
timeout_seconds = 60

[llm.remote]
base_url = ""
model = ""
profile_id = ""
timeout_seconds = 15

[delivery]
mode = "auto_paste"
shortcut = "platform_default"

[recovery]
persist = true
max_entries = 5
ttl_hours = 24
```

线程 0 表示自动，显式范围 1 至可用逻辑核数。上下文允许 2048–16384 且受模型上限约束。mode 枚举 local/remote，profile 枚举 cleanup/light，delivery 枚举 auto_paste/preview。语种枚举 auto/zh/en。ASR 后端允许 cpu/auto 和实际启用的 GPU 后端。超时及恢复设置有界，恢复最大 5 条、24 小时。控制器统一验证设置、凭据与模型引用。保存用同目录临时文件、刷盘后替换，失败保留旧配置。版本迁移保留原文件，无法解析或遇到较新 schema 时显示诊断，避免以默认值覆盖。快捷键变更注册失败时回滚旧绑定，重启时仍能打开设置页修复。凭据更新先保存新引用，再提交配置；失败时保留旧配置和旧密钥。已经开始的任务使用当时快照。

# 10. 验收矩阵

标记 A 为自动测试，M 为真实桌面手测。每项证据写入发布记录，报告设备、系统、模型哈希、后端、冷/暖状态和结果。真实焦点、麦克风与粘贴证据不能用 mock 代替。

| ID | 验收方法与通过条件 |
|---|---|
| V01 M | Omarchy 上用快捷键完成 20 次录音，每次一个任务，长按无重复录音。用原生 Wayland 编辑器、浏览器输入框及一个 XWayland 编辑器验证中英混排、多行和特殊字符逐字一致。确认无需提升权限 |
| V02 A/M | 用带 2 秒延迟的 provider 结果测试，推理时切换窗口、切回原窗口、关闭目标、锁屏或让焦点 IPC 断开，均无自动粘贴。终端默认手动。模拟 wtype 缺失、拒绝、超时，结果始终可访问，未知交付不自动重放 |
| V03 A/M | 在本地模型已安装、外网断开的条件下完成采集、ASR、本地 LLM、粘贴。用应用及其子进程的网络审计确认无外网连接。重新启网后重复本地测试，检查无后台探测 |
| V04 A/M | HTTPS 测试端点验证请求、Key 和 payload。中英文转写通过远程全流程。覆盖超时、断网、401、429、5xx、重定向、无效证书、空结果及截断。每例只发一次，Raw 逐字一致且不自动粘贴。重试无新增麦克风采集，失败结果重启后可恢复。用真实兼容服务完成一次合成样本文本测试 |
| V05 A | 单测覆盖所有表中状态转移、重复停止、忙时切换、取消与晚到结果、配置快照、脏/超长响应、长文本超限。注入“提交 Raw 后”和“发送粘贴前后”的崩溃，重启后 Raw 保留且无自动交付 |
| V06 A/M | 模型下载校验错误、中断、磁盘空间不足、格式不符、当前版本被引用。没有不完整可选模型，旧版本可继续运行。硬件建议不修改用户设置，不请求远程。模拟 GPU 加载失败后可显式用 CPU 重跑 |
| V07 M | 杀死任一推理子进程后 UI 仍响应，重试可重新创建。父进程退出后 5 秒内无推理孤儿。空闲到期后 5 秒内释放对应 worker。应用挂起/恢复与麦克风拔出后可完成下一次录音 |
| V08 A/M | 记录并检索日志、配置、数据库、子进程命令行，禁止出现合成 Key。原始 PCM 无磁盘文件及网络发送。换端点需重新确认并录入凭据。关闭持久化、清空和过期后验证恢复列表为空 |
| V09 M | Windows 11、macOS Apple Silicon 与 Intel、Linux X11 分别安装发布包，验证快捷键、设备授权、本地链路、目标校验和自动粘贴。测试拒绝授权、快捷键冲突、剪贴板占用或 UIPI 等对应路径。其他 Wayland 环境验证预览/手动复制 |
| V10 A/M | 用 ≥12 条中文、英文、中英混合真实或获授权音频，覆盖数字、专名、路径、否定、静音与口头禅。对冻结的文本 fixture 检查 ASR 预期及 LLM 改写。两个 LLM 模式各跑一轮，所有受保护事实保留，至少 10/12 条经人工判为可直接使用或只需标点修改。静音案例单独验收，无网络请求 |
| V11 M | 在记录清楚的 Omarchy 参考机上，以 warm Base 多语、CPU、内存至少 16 GiB，连续 20 次录制同一组 10 秒样本。P95 快捷键至录音指示 ≤300 ms、ASR 停止到提交原文 ≤5 秒、有效结果到粘贴派发 ≤500 ms。参考小型 1–3B Q4 本地模型 warm 全链路停止到派发 P95 ≤15 秒。分别报告冷加载及远程网络耗时。若参考硬件未达标，需量化差距并通过性能修复或经产品确认修订门槛 |

# 12. 风险与收口

| 风险 | 实施控制 |
|---|---|
| Hyprland 滚动更新改变语法、协议或焦点事件 | M0 锁定实测版本，每次发行记录兼容范围。版本未知重新探测。注入能力退化时保留完整手动流程 |
| 粘贴无消费回执、焦点存在竞态 | 结束时冻结目标、监控切焦、派发前复核、只派发一次。敏感应用与无法确认目标的场景使用预览 |
| 录音受权限、蓝牙切换、采样率变化影响 | 每次开始验证实际流，处理设备断开，测试至少内置与 USB 麦克风，超时复位 |
| 旧 CPU 指令集与 GPU 驱动兼容性 | 按架构验证 CPU 基线，打包可运行的目标指令集。GPU 探测和加载失败独立降级，推荐允许用户覆盖 |
| 远程兼容端点偏差、费用与敏感内容上传 | 最小请求合同、显式测试与确认、15 秒默认超时、用户触发重试、保留原文。请求发出后按供应商规则处理 |
| 小模型改写数字、术语和否定句 | 两种处理档案共享保真规则与输出校验，运行固定样本门槛。原文可查并可复制 |
| 模型许可、供应链和资源峰值 | 锁定源码、逐模型验证许可证和哈希、资源预算先于加载、版本目录并存 |
