## 已验证的 Lua 片段语义

```lua
o.bind("SUPER + SHIFT + D", "Voice input", "/usr/bin/voice-inputctl toggle", { release = true })
```

上面仅用于模拟检查，不是可安装配置：CLI 尚未实现，默认组合存在静态冲突。没有写入 `~/.config/hypr/`，没有调用 reload。真实安装前必须重新读取 `hyprctl binds` 并选定空闲组合。

本机依据：`/usr/share/omarchy/default/hypr/bindings/voxtype.lua` 的 F9 stop 使用 release=true；`helpers.lua` 的 o.bind 原样传递选项。公开规格中的两个 Hyprland Binds URL 本次文档抓取返回 404，未据此猜测新版语法。
