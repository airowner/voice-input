## 本轮实现决策及退出边界

生产输入从不兼容的 `wtype` 固定按键调用改为内部 Wayland virtual-keyboard-v1 适配，仍仅发一次 Ctrl+V，不发送文本/Enter、不激活旧窗口，不使用 root、uinput、额外守护进程或 sidecar。固定 pc/us 键图在启动后台准备；未就绪则手动。协议与最后焦点查询共享 500ms 截止时间，可能已发输入后的错误为 Unknown，不重发。实现与局部 socket/真实子进程测试见 [原生键盘验证](evidence/native-keyboard-verification.json)。这是实测兼容性修复，原规格及验收门槛不改。

20 次 Wayland 浏览器生产 adapter 粘贴调用全部通过，P95 194.804ms；范围仅 copy+guard+原生协议 ACK，未含控制器持久化、UI、录音、ASR 或 LLM，不能算 V11 全程 P95。[逐条记录](evidence/browser-paste-wayland-20.json)保留全部样本。

本快照尚不登记新 release/安装包通过，也不抢先认定待补的 GTK 生产路径结果。完整验收状态及剩余门槛见 [ACCEPTANCE.md](ACCEPTANCE.md)，阶段入口见 [PROGRESS.md](PROGRESS.md)。

### 首次静态与模拟 Lua 检查（历史）

```lua
o.bind("SUPER + SHIFT + D", "Voice input", "/usr/bin/voice-inputctl toggle", { release = true })
```

上面仅用于模拟检查，不是可安装配置：CLI 尚未实现，默认组合存在静态冲突。没有写入 `~/.config/hypr/`，没有调用 reload。真实安装前必须重新读取 `hyprctl binds` 并选定空闲组合。

本机依据：`/usr/share/omarchy/default/hypr/bindings/voxtype.lua` 的 F9 stop 使用 release=true；`helpers.lua` 的 o.bind 原样传递选项。公开规格中的两个 Hyprland Binds URL 本次文档抓取返回 404，未据此猜测新版语法。
